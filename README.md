# أدوات PDF (PdfToolkit)

مشروع Android (Kotlin + Jetpack Compose) للاستخدام الشخصي.

## البناء
1. افتح المجلد في Android Studio (إصدار حديث، Hedgehog أو أحدث) ودع Gradle يكمل المزامنة.
2. وصّل هاتفك (تصحيح USB) أو شغّل محاكياً، ثم Run.
3. للحصول على ملف APK: Build > Build Bundle(s) / APK(s) > Build APK(s)
   الناتج: app/build/outputs/apk/debug/app-debug.apk

الحد الأدنى: Android 10 (API 29). النتائج تُحفظ في Download/PDFToolkit.
